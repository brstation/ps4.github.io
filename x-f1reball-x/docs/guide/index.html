PS4 jailbreak host in the browser.

ps4jb is a PS4 jailbreak and HEN host that runs in the PS4 Internet Browser. It picks a jailbreak chain from your firmware. Coverage 6.00–12.02 and 12.50–13.52, proven on 13.02, 13.04, 13.50 and 13.52.

Live host: https://x-f1reball-x.github.io/ps4jb/

Open the hostSource on GitHub

Requirements

  • A PS4 on a supported firmware (see below).
  • The PS4 Internet Browser.
  • Optional: the update-blocking DNS.

1. Block updates (DNS)

Optional but recommended. DNS by Nomadic blocks official system updates.

  1. Settings → Network → Set Up Internet Connection
  2. Choose Custom setup
  3. DNS Settings: Manual
  4. Primary DNS: 62.210.38.117
  5. Leave Secondary DNS empty
  6. Save and test the connection (failing to reach Sony is OK)

2. Open the host

  1. Open the PS4 Internet Browser.
  2. Clear Cookies and Clear Cache (Options menu).
  3. Go to https://x-f1reball-x.github.io/ps4jb/
  4. Add the page to Favorites.

3. Jailbreak

  1. Open the favorite / link.
  2. Wait for Cache ready, then the jailbreak starts by itself.
  3. Wait for success (the page tries to close).
  4. If it fails, restart the console and try again.

To override the automatic choice, add ?chain= with cssfontface, psfree, slopkit or relapse.
